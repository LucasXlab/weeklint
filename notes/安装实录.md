# 冷启动安装实录

目标：在一个全新的空目录里，只按 `README.md` 的快速开始走，记录每一步的真实输出、耗时和踩坑。若任何一步失败、文档没写清楚、或首次结果超过 5 分钟，就回到 README/安装路径修。

日期：2026-10-29 19:48（America/New_York）。
环境：macOS 15（darwin 24.x），Python 3.13.5，`pip 25.1.1`，Node/Playwright 仅用于截图，不参与安装。
测试目录：`/tmp/weeklint-final`（clone）、`/tmp/weeklint-final-home`（工作目录）。

## 步骤与结果

### 1. 克隆

```bash
cd /tmp
git clone /Users/you/NO/weeklint /tmp/weeklint-final
```

- 结果：成功，仓库自带的 `.gitignore` 排除了 `.venv/`、`__pycache__/`、`.weeklint/`、`dist/`。
- 没有 remote，`git clone` 使用本地路径；这与 README 的「在仓库根目录安装」一致。

### 2. 创建虚拟环境并安装

```bash
cd /tmp/weeklint-final
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .
```

- 结果：成功。安装 `icalendar 6.3.2`、`python-dateutil 2.9.0.post0`、`PyYAML 6.0.3`、`rich 13.9.4` 及传递依赖。
- 耗时：从 clone 开始到 `weeklint --version` 可用约 6 秒（本机有 wheel 缓存）。
- 已知无关警告：`pip` 提示用户级 cache 目录不可写，已自动禁用 cache；不影响安装。README 不需要为此增加步骤。

### 3. 初始化工作目录

```bash
mkdir -p /tmp/weeklint-final-home
cd /tmp/weeklint-final-home
weeklint init
```

真实输出：

```text
已创建 weeklint.yaml、tasks.md、calendar.ics。下一步：导出日历到 calendar.ics，再运行 weeklint check。
目录：/private/tmp/weeklint-final-home
```

生成：

```text
calendar.ics
tasks.md
weeklint.yaml
```

- `weeklint.yaml` 的 `timezone` 自动写成机器的 IANA 时区（本机 `America/New_York`）；这是 README 说「最少只需要改两处」的第一处。
- `tasks.md` 只有 3 行注释，没有假任务；第一次 `check` 不会看到占位内容。
- `calendar.ics` 是合法的空 VCALENDAR。

### 4. 第一次 check

```bash
weeklint check --now 2026-11-02T09:00:00-05:00
```

真实输出：

```text
2026-W45 · 2026-11-02 至 2026-11-08
可支配 37h30m · 任务需要 0m · 缺口 0m
 任务文件里没有未完成任务：/private/tmp/weeklint-final-home/tasks.md。
```

- 退出码 0。
- 从 clone 到第一次结果：**6 秒**，低于 5 分钟目标。
- 没有配置真实日历时也给出可解释的容量；不会因为空日历报错。

### 5. 用示例输入走完整流程

为了验证真实使用而不是只有空目录，把仓库 `examples/` 的三个文件复制进工作目录：

```bash
cp /tmp/weeklint-final/examples/{weeklint.yaml,tasks.md,calendar.ics} .
weeklint check --now 2026-11-02T08:30:00-05:00
weeklint plan  --now 2026-11-02T08:30:00-05:00
weeklint today --now 2026-11-02T08:00:00-05:00
weeklint explain 论文 --now 2026-11-02T08:30:00-05:00
weeklint doctor --now 2026-11-02T08:30:00-05:00
```

结果：

- `check` 退出 0；可支配 24h30m，任务需要 11h45m，缺口 0；一条 `task_unestimated` warning（示例故意留的）。
- `plan` 退出 0；已排 11h45m，未排 0；写出 4 个文件。
- `today` 退出 0；显示 09:00–10:00、15:40–17:10，下一块 09:00。
- `explain 论文` 退出 0；状态「已排」，两个块都标记「已锁定=是」。
- `doctor` 退出 0；任务 7、事件 8、可用 24h30m。

输出文件：

```text
.weeklint/plan.ics       2.2K
.weeklint/plan.json      4.6K
.weeklint/plan.md        793B
.weeklint/report.html    9.8K
```

`report.html` 检查：

- 浏览器打开无控制台错误；
- 1280px 浅色/深色和 375px 三张截图都成功，`scrollWidth == clientWidth`（375px 无横向滚动）；
- 无 `<script>`、无 `http://`/`https://`、无 `url(`；
- 颜色全部来自 CSS token。

### 6. 卸载/清理

```bash
rm -rf /tmp/weeklint-final /tmp/weeklint-final-home
```

没有系统级安装、没有后台进程、没有写入 `~` 之外的位置（示例工作目录除外）。

## 安装结论

- README 的步骤可以零改动跑通；首次结果 6 秒，远低于 5 分钟。
- 没有出现「文档没写但必须知道」的知识。唯一需要注意的是：真实使用前必须把日历导出为 `calendar.ics`，README 已写。
- 失败重试：无；安装路径不需要调整。
